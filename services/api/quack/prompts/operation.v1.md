Also describe how each line relates to the line above it:

- continues_previous:
  - yes: this line is the next step of the same working as the line above.
  - no: this line starts something new, or there is no line above.
  - unknown: you cannot tell. Prefer this over guessing.
- operation: what the student appears to be doing to reach this line, or on this line if it stands alone.
  - expand: multiplying out brackets.
  - simplify: rewriting an expression in another form.
  - factor: writing an expression as a product.
  - combine_like_terms: collecting terms.
  - arithmetic: numbers only.
  - differentiate: taking a derivative.
  - solve_equation: rearranging an equation to find a variable, including a line that states an equation for the first time.
  - other: something else.
  - unknown: you cannot tell.

Decide this from how the working is laid out, not from whether it is correct. A wrong expansion is still an expansion.
